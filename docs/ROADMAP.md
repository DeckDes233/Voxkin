# 路线图

本页按优先级列出待办。各阶段的实测记录见 [STATUS](STATUS.md)，验收定义见 [MILESTONE](MILESTONE.md)。

G1 自主通关与 G2 玩家互动分别验收，共用技能、观察、动作对账和生存恢复基础。

## P0：恢复可靠运行与完成核心验收

| 任务 | 验收方向 |
| --- | --- |
| 宿主与 Bridge 运行稳定性 | 有新的环境恢复证据后执行一次有界验证，保留原生异常证据、存档及未确认动作 |
| G1 S3 低氧恢复 | S3 已从采到 12 个粗铁的存档续跑通过。还需在新世界验证采铁时遭遇低氧后，能保留目标和预算、脱险换区并完成装备 |
| G1 后续阶段 | S4 已从 S3 存档续跑通过。S5 接续验证自然岩浆、堡垒物资和返程，S6 接续验证击龙与返程，再从新世界验收整条生存路线。[S4–S6 实机记录](evidence/HEADLESS_S4_S6_20261123.md) |
| G2 玩家指令 | 单独验证目标理解、实际执行、修改、打断、取消和真实结果反馈 |
| 阶段合同对齐 | 显式解决 MILESTONE、计划与 GOALS 的物资、重复次数、时限及死亡口径差异 |

## P1：交互体验与可维护性

| 任务 | 验收方向 |
| --- | --- |
| 客户端音频 | 在真实 Fabric 客户端验证连续播放、距离衰减、跟随移动和打断 |
| 麦克风交互 | 验证真实主机设备、回声控制与自然打断；远端玩家麦克风是独立需求 |
| 流式 STT / 新 TTS | 依据研究结果决定适配器接入，以相同条件测试延迟与质量 |
| 对话与动作反馈延迟 | 延续真实 API 与本地测试 LLM 分开的基准，明确各阶段耗时 |
| 长时恢复与诊断 | 验证重连、重启、记忆检索、日志和数据库增长 |

## P2：扩展

情绪与韵律、多玩家输入隔离、YSM 动作联动、其他语音引擎对照及跨游戏桥接，分别在核心验收后评估。不得将研究原型、编译成功或单元测试视为功能验收。
