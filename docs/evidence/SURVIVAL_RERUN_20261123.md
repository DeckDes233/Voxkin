# S1–S6 生存复测

使用 Java 版 1.21.1 的无头 Paper、正式 Studio、Mineflayer 和 RunManager。固定种子 `20261022`，从无玩家数据和任务记录的新世界开始，普通难度，空背包。阶段间保留同一角色、地形和物资。文字输入、静音输出，未配置 LLM。原始观察、日志和阶段回执位于本地 `work/live_adaptive_20261122/roundchain1/`。

| 阶段 | 新世界连续运行结果 |
| --- | --- |
| S1 | 自行伐木、采石，做出石镐、石剑和熔炉，正式验收通过 |
| S2 | 自行狩猎、收集羊毛并准备庇护所，正式的过夜准备验收通过 |
| S3 | 从本轮 S2 的背包开始，自行采铁、熔炼并做齐铁镐、铁剑、盾牌和桶。角色满血，正式验收通过 |
| S4 | 在这条生存线的存档中续跑，角色自行补木、补镐，采到四颗钻石，用三颗合成钻石镐。正式验收通过并自动开始 S5 |

S4 缺木入夜时，角色站在 (-0.5, 75, 77.5)，能观察到约 22 格外的床，却持续在露天等待。修正夜间规划并将技能的搜索半径传给实际睡床动作后，`roundchain2` 暴露了第二个问题：Bridge 因观察版本已过期在动作启动前拒绝准入，规划器却已记为当夜尝试过。现只按已发生的物理失败限制当夜重试。恢复同一个任务和存档的 `roundchain3` 再次遇到过期准入，随后自动重试成功。Paper 记录 Sweet Dreams，角色在 (0, 64, 96) 睡到次日 06:00，并继续采木。Java 版在夜间允许睡床，实际使用需要靠近床，附近敌对生物可能阻止入睡。[Minecraft Wiki 床](https://minecraft.wiki/w/Bed)

下界侦察将失败的进路连同出发位置传入下一次搜索。只有从相近起点走向相近目标才跳过这条路，到过的落脚点单独记录。末地栖息战中，角色受伤且能够通过饥饿值或食物恢复时，可以在没有箭的情况下撤离休整。上轮的低血量实测记录和存档条件见[末地战斗记录](HEADLESS_S4_S6_20261123.md#s6-末地战斗存档)。[Minecraft Wiki 末影龙](https://minecraft.wiki/w/Ender_Dragon)

## 关机后复测

宿主重启时间晚于旧运行的启动时间，Paper、Bridge 和运行器均已退出，三个端口均已释放。SQLite 完整性检查通过，世界元数据及玩家存档可解压读取。保留旧存档，在副本上重启 Paper 1.21.1。Core 自动恢复的 S4 任务 4 按原截止时间返回 `budget_elapsed`。随后在同一世界新建任务 5，续测时继续使用其任务账本。原始回执在本地 `work/live_adaptive_20261122/` 下的 `reboot*` 目录。

- **S4 生存线。** 地形检查显示，西侧较近的橡树隔着水面，东侧的树有陆路可以绕行。日志还记录到角色在暗处追地表树时看到了上方的见天出口。改为先处理已观察到的出口，远程采木按干地连通性选树并逐段验收。换区现在核对 S4 动作的真实起点和终点。`reboot4` 到达东岸，`reboot5` 在 (107.5, 64, 21.5) 取得橡木原木。
- **S5 下界对照。** `reboot-nether` 从前一轮下界存档出发。动作回执提供了 14 条走不通的进路，下一次侦察接收到这些记录并继续向外移动。安全动作随后接管，在岩浆怪群中切换攻击目标。角色从约 X=33 走到 X=50 后死亡，Paper 记录了落入岩浆。针对这一处，主动侦测到岩浆怪时先退避，下界撤退要求落脚点有支撑，并限制途中落差。
- **S6 末地对照。** `reboot-end` 使用此前清除水晶后的存档，角色残血、无箭，龙有 104.94 点生命。没有增加物资。角色吃下熟牛肉，之后在祭坛附近以 13.77 点生命受到龙的攻击，Paper 记录角色被龙击杀。此轮暴露出龙起飞时无箭角色会在回血途中提前返回祭坛。

`reboot5` 随后沿阶梯进入钻石矿层，Paper 记录了 Diamonds!。铁镐耗尽时，角色位于 (120.5, -12, -14.5)，生命 20、饥饿值 17，背包里有两颗钻石、八块橡木原木、四根木棍、一块粗铁和三块煤。桥接现在会在铁镐损坏、现有工具无法采下钻石矿时结束当前采集动作，让规划器根据背包重新备镐。[Minecraft Wiki 钻石矿石](https://minecraft.wiki/w/Diamond_Ore)

`reboot6` 从断镐处恢复任务 5。角色先做石镐、补木棍，把粗铁采到七块，熔炼三块并合成铁镐。重新采钻石后背包有四颗，就地放工作台制成一把钻石镐。正式阶段回执为 `goal_status=done`、`stage_complete=true`，验收时剩一颗钻石、生命 20、饥饿值 16，随后自动进入 S5。

`reboot-nether2` 从与上次落岩浆相同的存档重跑。寻路器多次返回没有可行路线，结束本次观察时角色仍在下界 (39.5, 94, 6.3)，生命值始终为 15.10，未发现堡垒，未获得烈焰棒或末影珍珠。这次未观察到上轮的落岩浆，也没有足够证据将生还归因于避让岩浆怪。

`reboot-end2` 从同一个 2.17 点生命的存档复测，进场即观察到约 3 格外的龙息，Paper 记录角色死于末影龙的魔法伤害。此次来不及观察龙起飞后的无箭撤离。[Minecraft Wiki 龙息云](https://minecraft.wiki/w/Ender_Dragon#Dragon_fireball)

`reboot-end3` 改从此前的 `s6cage4` 末地战斗存档继续。该存档此前清除了附近的末影人，角色戴着雕刻南瓜，水晶已清空。本次沿用其背包和地形，首次观察到角色有 52 支箭、55 块熟牛肉、12.77 点生命。箭用尽后，阶段因连续安全抢占耗尽重评预算而停止。终态仍在末地，角色有 15.83 点生命、51 块熟牛肉。对比两份停服后的末地实体存档，龙的生命从 192.46 降至 186.46，水晶数均为零。此轮未击龙、未返程。

## 自然生存线的 S5 起点

`reboot6` 的 S5 首先熔炼了一块铁锭。准备出洞狩猎时，角色在 (119.5, -12, -16.5)，庇护所在 (1, 63, 97)，水平相距约 164 格。没有观察到附近露天出口。规划器把庇护所距离与 128 格上限比较，尚未走第一步就返回 `s5_dependencies`。修正后，地底补给可朝已知锚点分段上行，每段最多水平约 6 格、上升 8 格，每段核对实际坐标。临近地表继续检查昼夜和附近危险。

`reboot7` 从同一矿底恢复 S5 任务 6，连续三段上行收到成功回执。角色从 Y=-12 爬至 Y=11，随后局部寻路反复超时，耗尽方法重试预算。停服时在主世界 (106.5, 11, -2.5)，生命 20、饥饿值 14。这条生存线保留了钻石镐，尚未进入下界。

## 末影之眼与要塞对照的口径

Java 版的眼指向要塞起始楼梯所在区块。角色还要自行探索才能找到传送门房。旧对照用服务器指令定位要塞，把角色放到离定位点约 172 格的地方并补给物资。角色随后确实投过眼，但旧版还会搜索已加载区块：在 Y=55 时就读到了 Y=-6 的五个门框。这段只验收投眼、下探和后续入门动作；从自然起点寻找要塞和门房仍待验收。[Minecraft Wiki 末影之眼](https://minecraft.wiki/w/Eye_of_Ender) · [原始对照条件](HEADLESS_S4_S6_20261123.md#s6-要塞与末地门对照)

正式寻门动作使用末影之眼实体的飞行方向和多次投掷的交点估算要塞方位。门框发现、主世界末地门激活以及 Studio 门房观察现在都用 Mineflayer 的视线射线过滤方块。Core 只接受带视线确认的门框回执，恢复旧任务时会清除过去隔墙扫描得到的门框坐标。

| 无头 Paper 对照 | 相同场景下的实测 |
| --- | --- |
| `reboot-eyes`，门房上方 Y=55 | 保留角色和投眼轨迹，清空诊断输入里的旧门框坐标。激活动作在 64 格范围未发现门框。同一角色从旧投眼轨迹分段下探至 Y=47，门框仍为零，回执保留了继续搜索的状态。 |
| `reboot-eyes-room`，天然门房内 Y=-5 | 沿用门房内角色存档，只读现场观察。视线确认了 12 个门框，其中 10 个已有眼、2 个待填。 |

两次均未执行定位、传送或给予物品的指令，使用了原先要塞对照的场景存档，只用于检验遮挡。原始动作、坐标、世界观察与干净停服回执保存在对应的本地 `result.json`。

本轮离线回归通过 Python 588 项（56 条警告）、Bridge 344 项。离线用例含确定性世界与引擎替身；上表观察来自真实无头 Paper 1.21.1。
