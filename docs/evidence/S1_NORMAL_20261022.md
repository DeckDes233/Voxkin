## 本轮修掉的采集崩溃

第一次跑 S1 时，`mine_collect` 在捡圆石阶段抛出：

```text
动作 mine_collect 执行失败: pos.floored is not a function
```

根因：`gather.js` 把普通 `{x, y, z}` 对象传给 `bot.blockAt()`。`prismarine-world` 的
`WorldSync.getBlock()` 会执行 `block.position = pos.floored()`，区块未加载时提前返回 null 不报错，
区块已加载时就必然抛错。旧代码只有在掉落物或危险扫描落到已加载区块时才会触发。

修法：在 `bridge/skills/gather.js` 增加 `toVec3()` 与 `blockAtPos()`，把文件内 22 处
`bot.blockAt(...)` 统一改成 `blockAtPos(bot, ...)`，用 bot 自己的 Vec3 构造器转换坐标；
构造失败时退回 `base.offset(...)`。修复后同一个 S1 计划一次通过 5/5。
