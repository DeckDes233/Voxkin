## 文档职责

README 保留项目概览和安装入口；STATUS 汇总当前结论并链接证据；MILESTONE 定义目标并标明合同差异；架构文档说明实现边界。`plans/` 是设计与验收计划，`research/` 是调查材料，`evidence/` 是带环境和时间范围的验证记录。

历史记录中的测试数字或“已通过”只适用于当次运行，不自动代表当前工作树、正式 G1/G2 验收或宿主问题已修复。最新活动状态还需读取本地 marker。旧文件路径保留，避免破坏现有引用。
