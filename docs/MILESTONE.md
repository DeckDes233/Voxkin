# 最终里程碑：独立通关 Minecraft

> 最后的milestone是沃心独立通关一次mc，全流程，我只负责旁观。

这句话是项目的最终验收标准，写在最前面，后续所有阶段都为它服务。

## 完成定义

从空背包、生存模式、默认难度开始，沃心在没有人干预的情况下完成：

1. 木头 → 工作台 → 木镐；
2. 石头 → 石镐、石剑、熔炉；
3. 食物与过夜庇护所；
4. 铁装、盾、铁镐；
5. 钻石、附魔台；
6. 下界门、烈焰棒、末影珍珠；
7. 要塞、末地门、末地水晶；
8. 击败末影龙。

“没有人干预”包括：不补物品、不报坐标、不救场、不手动暂停、不改游戏规则。允许观察、录屏和事后看日志。

## 必须自己处理的情况

- 死亡与重生，包括掉落物回收或放弃；
- 卡住、寻路失败、区块未加载；
- 夜晚、饥饿、低血、岩浆、仙人掌、苦力怕；
- 背包满、工具损坏、床或传送门被破坏；
- 桥接断线、Core 重启、服务器重启、模型限流；
- 长时间运行后的内存、日志与数据库增长。

## 非目标

- 不用创造模式、作弊命令、外部地图工具或人工补给完成正式验收；
- 不追求速通纪录，优先稳定与可恢复；
- 不要求一次不死，但要求死后能自己继续；
- 不把“玩家在旁边看着”当成隐性帮助。
